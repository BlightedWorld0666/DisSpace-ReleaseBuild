# DisSpace

Official Windows desktop downloads for DisSpace.

Download **DisSpace.exe** from [Releases](https://github.com/BlightedWorld0666/DisSpace-ReleaseBuild/releases/latest). If the first release is still being prepared, check back shortly.

DisSpace is free. Updates are checked inside the app, and future desktop downloads do not require a GitHub token.

This repository distributes the desktop executable and release information. Application source code and the private administration server are not published here.
